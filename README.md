# База знаний по растениям

Современная база знаний с древовидной навигацией, системой управления статьями и профилем автора.

## 🌿 Основные возможности

### Навигация по статьям
- **Древовидная структура категорий** с подкатегориями
- **Система тегов** для быстрой фильтрации
- **Поиск** по всем материалам базы знаний
- **Навигация по содержанию** статьи с прокруткой к разделам

### Управление материалами
- **Рабочий кабинет** с вкладками:
  - Черновики
  - Опубликованные
  - На проверке
  - Архив
  - Корзина
- **Мои комментарии** — все комментарии пользователя с рейтингом
- **Мои вложения** — файлы и изображения с поиском и управлением

### Профиль автора
- Статистика: количество статей, рейтинг, комментарии, просмотры
- Детализация рейтинга: качество, активность, полезность
- Список последних статей с возможностью просмотра всех

### Система уведомлений
- Уведомления о новых комментариях
- Статусы модерации
- Системные сообщения
- Фильтры: все / непрочитанные / прочитанные

## 📑 Варианты навигации по содержанию статьи

### Вариант 1: Вкладки в левой панели (Реализован)

В левой панели при открытии статьи появляются две вкладки:
- **Категории** — стандартная навигация по дереву категорий
- **Содержание** — нумерованный список разделов текущей статьи

**Преимущества:**
- Всегда виден список разделов
- Не занимает место в области статьи
- Быстрый переход между разделами
- Левая панель фиксирована при прокрутке

**Демо:** Откройте `public/sticky-toc-demo.html` в браузере

### Вариант 2: Sticky кнопка в статье (Демо)

Кнопка "Содержание" расположена в начале статьи и остаётся видимой при прокрутке:
- Компактная кнопка с иконкой списка
- Открывает popover со списком разделов
- Всегда доступна при прокрутке (sticky)
- Не требует переключения вкладок

**Преимущества:**
- Не требует переключения между вкладками
- Всегда видна при прокрутке
- Компактный интерфейс
- Быстрый доступ к навигации

**Демо:** Откройте `public/sticky-toc-button-demo.html` в браузере

## 📊 Примеры данных

### Длинная статья с навигацией
Статья "Полное руководство по выращиванию фиалок" содержит 11 разделов:
1. Введение
2. Выбор сорта
3. Подготовка грунта
4. Освещение
5. Полив
6. Подкормки
7. Пересадка
8. Размножение
9. Болезни и вредители
10. Стимуляция цветения
11. Заключение

### Категории
- Комнатные растения (фиалки, орхидеи, кактусы, суккуленты, пальмы, фикусы, папоротники, алоэ)
- Садовые растения (розы, пионы, хризантемы, лилии, георгины)
- Деревья (плодовые, декоративные, хвойные)
- Посадка и уход (почва, полив, удобрения, обрезка)
- Луковичные (тюльпаны, нарциссы, крокусы, гиацинты)
- Травы и специи (базилик, мята, розмарин)
- Вредители и болезни (тля, паутинный клещ, грибковые заболевания)
- Ландшафтный дизайн (клумбы, альпийские горки, газон)

- **Vite** — сборщик
- **SVG** — иконки

## 📝 Примечания

- Все данные хранятся в `src/data/categories.ts`
- Для добавления новых категорий/статей редактируйте файл данных
- Система поддерживает вложенные категории (до 3 уровней)
- Статьи могут иметь разделы для навигации по содержанию
